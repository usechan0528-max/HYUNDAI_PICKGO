Pleos Connect 개발 시작 키트
버전 1.1 · 2026년 11월 1일 KST

역할
- Codex: 메인. 전체 기획·조사·설계 제안·구현·넓은 검증·통합·버전·문서·인수인계.
- Claude Code: 범위가 한정된 보조 작업과 독립 검수. 기본은 소스 수정 없는 검수이며, 작은 수정은 목표·허용 파일을 명시해 따로 위임.
- 사용자: 앱 주제·새로운 범위·공개·제출 등 승인 사항을 결정.

사용 순서
1. 아래 지침 파일을 프로젝트 루트에 배치한다. 동명 파일은 덮어쓰지 말고 비교 후 병합한다.
2. START_PROMPT.txt의 Codex 메인 시작 프롬프트로 계획을 세우고 주제·범위를 승인한다.
3. Codex가 의미 있는 이정표마다 필요한 diff·파일·요구사항·증거만 묶어 Claude에 전달한다.
4. Claude의 검수 결과 또는 작은 패치를 Codex가 판단·통합·재검증한다. 전체 이력을 반복 전달하거나 같은 기능을 다시 구현시키지 않는다.

포함 파일
- DEVELOPMENT_GUIDE.md: 공통 개발 기준의 단일 원본
- AGENTS.md: Codex 메인 진입 지침
- CLAUDE.md: Claude 서브·검수 진입 지침
- START_PROMPT.txt: 시작·위임·독립 검수·작은 수정·통합 프롬프트
- Pleos_Connect_개발기준과_시작프롬프트.docx: 읽고 수정할 수 있는 통합 문서

주의
앱 주제는 아직 미확정이다. 역할 분담만 확정했으며 코딩·공모전 접수를 승인한 것은 아니다.
두 제품의 자동 호출·문맥 공유·토큰 공유를 전제하지 않는다. 한도와 사용량을 추정하지 않는다.
공개·외부 제출·push·계정·권한 변경은 별도 승인 사항이다.
문서를 작성·검수했으며 앱 소스 작성, SDK 확보, 빌드·테스트·에뮬레이터 실행, APK 생성은 하지 않았다.
