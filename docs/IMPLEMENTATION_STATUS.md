# PICKGO 구현 및 검증 범위

기준일: 2026-11-06. 로컬 웹 프로토타입과 별도 Android 내비 시연 앱을 구분합니다.

## 구현 상태

| 영역 | 제공 기능 | 범위와 제약 |
|---|---|---|
| 단일 픽업 | 검색·지도·초대·준비·장소 합의·도착·탑승·종료 | 양재 OSM 수록 지역, 메모리 저장 |
| 다인 픽업 | 사람별 초대·공동 승차·수동 순서·탑승·취소 | 회차 총 6명, 실제 차량 정원 별도 준수 |
| 위치 공유 | 동의·일회 공유·거부·중지·삭제 | 브라우저 구현, 물리폰 HTTPS 전체 검증 미완료 |
| UI | 장소의 좌표형 문구 정리·모바일 한 열·스크롤·초대 지점 안내 | 현재 소스에 반영. 기존 영상은 개선 전 화면 포함 |
| 현대 내비 | OSM 단일 확정 좌표를 NaviHelper 3.0.5로 전달 | 별도 Android 앱·Pleos 에뮬레이터 확인 |
| 합성 추천 | 지점·순서 추천과 근접 판정 모듈 | 합성 입력 전용, 일반 화면 일부 설정 숨김 |
| Gleo/routo | 계약·어댑터 및 시험 준비 | 실제 서비스 통합 미완료 |

## 확인한 검증

- 웹: `npm test`와 동일한 Node 내장 시험 집합 261개 통과. 마지막 실행 2026-11-06.
- UI: 7개 크기에서 89개 레이아웃·상태 검사 통과. 이는 모든 기기 호환성 인증이 아님.
- Chrome: 단일 픽업 완료, 다인 3명·2지점 공동 승차 완료, 공동 지점 일부 탑승 상태에서 진행 제한 확인.
- Android: 2026-11-06 당시 debug 빌드·lint 실행 완료. lint 오류 0, 경고 3(의존성·백업 규칙·아이콘 관련).
- 내비 정책: RouteGateTest 43 assertions 통과.
- 에뮬레이터: 단일 확정 목적지 일치·ROUTE_GUIDING 및 45초 관찰 후 결과 유지 확인. 현재 UI 개선 이후 APK 전체 재검증을 뜻하지 않음.
- 지도: 로컬 OSM 지점 검사. 실제 정차 허용·현장 표지의 완전성 보장 아님.

## 실행 재현

```sh
npm start
npm test
```

- Node.js 22 이상. 기본 주소 `http://127.0.0.1:4180`.
- 외부 API 키 없이 기본 웹 시연 가능. 배경 지도는 OSM 타일 인터넷 연결 필요.
- 기본 데이터는 서버 메모리이며 재시작 시 소실. 회차 최대 24시간.
- 지도 데이터는 수집 시점부터 7일 유효. 만료 시 데이터 갱신 필요: [지도 안내](../experiments/pickup-board/map/README.md).
- Android 실행에는 별도 로컬 SDK·빌드 도구·키 설정 필요: [Android 안내](../experiments/pickgo-navigation/README.md).

## 미완료

- 실차, 차량 주행 UX 제한 연동, 공개 HTTPS 운영, 물리 휴대폰 전체 흐름.
- 실제 도로 이동시간 공급자, 현대 내비 다중 경유, Gleo 실제 음성 호출, routo 본연동.
- 공모전 release APK 생성·서명·배포 검증. 현재 debug 시연 파일을 release로 표시하지 않음.
- 본 문서는 구현·실행 범위 안내이며 공모전 제출 완료 또는 차량 안전 인증을 의미하지 않음.
