# J1 주력안: 실제 제품까지 남은 차이

D-014 주력 유지. 이 문서는 90점 달성 주장이나 새 기능 확장이 아니라 현재 증거와 미완료 범위의 구분이다.

|제품 요구|현재 증거|다음 수용 증거|
|---|---|---|
|목적지 없는 경로 추정|합성 구역 순서의 정확한 prefix 일치|위치 잡음·우회·같은 초반경로·처음가는곳을 포함한 관측 재생과 시간순 분리 평가; 실사용 정확도는 별도|
|차량 위치 입력|실제 SDK getter와 단일 Java매퍼 컴파일|Android환경의 SDK지원/권한/초기화/null/끊김/콜백해제 실행 기록|
|명시 내비 목적지 우선|공개 목적지/주행 콜백, 주행시간초 계약|내비활성/변경/취소/종료/지연응답에서 이전목적지를재사용하지않는통합 실행|
|주제와 취향의 결합|수동 가중치로 가상 두 주제 선택|실제 콘텐츠 카탈로그와 사용자 선택 비교; 같은 콘텐츠 노출 조건 유지|
|실제 콘텐츠 재생|현재재생 ID를 보존하는 큐 정책|재생/일시정지/이어듣기/오디오포커스/프로세스재시작 실행|
|운전 중 사용할 화면|구현없음|최소 조작 화면과 플랫폼 UX 제한 변화 시험|
|개인 기록 처리|메모리 이력/파생큐 삭제|저장·프로필분리·철회·영구삭제·로그확인 실행|
|반복 이용 가치|사용자가 밝힌 콘텐츠 선택 번거로움|컨텍스트 추천이 선택수고/정정수고를 줄이는지 실제 비교; 빈도·만족도 추정금지|
|콘텐츠 공급과 사업|가상 카탈로그만 존재|사용 가능한 콘텐츠와 재생범위/제공비용/출처 계약; 수익 가정과 근거 분리|

## 우선순위 결정 원칙
- 실제 선택 경험을 보여주는 시연과 SDK 실행 준비를 구분한다. 합성 실험을 늘리는 것만으로 제품 차별성을 증명할 수 없다.
- 사용자 효과 시험 전에 최소한 콘텐츠를 실제로 고르고 듣는 흐름이 있어야 한다. 순서표에 나온 가상 추천 차이를 선호 정답으로 삼지 않는다.
- 필요한 Android 개발 도구는 표준 경로에서 미발견이다. 현재 JDK26 단일 --release17 컴파일은 Android 도구체인 선택을 대신하지 않는다.
- 외부모집/계정/권한 변경 등 별도 승인 경계는 유지한다. 허용된 로컬 구현·문서조사·최소 Claude 협업은 이어간다.

## 다음 로컬 시연의 수용 조건 초안
- 사용자가 선택할 취향과 출발 상황을 제공하고, 현재 추천 1개 및 짧은 선택 근거를 표시한다.
- 반복 출근/같은 시각 다른 용무/목적지 미확인/위치 단절을 명시한 합성 운행 전환을 제공한다. 조작 패널은 시연 전용이며 실제 주행 상태 변경 버튼으로 설명하지 않는다.
- 직접 작성하거나 재생 권리를 확인한 콘텐츠만 사용한다. 실제 듣기 흐름이 없다면 콘텐츠 효과 검증이라 부르지 않는다.
- 재생 중에는 경로 변화가 현재 콘텐츠를 끊지 않고 다음 추천에 반영됨을 관찰할 수 있어야 한다.
- A/B/C 입력 전략의 차이와 같은 추천이 나오는 경우를 모두 노출한다. 정답·승자·효과 수치를 만들어 표시하지 않는다.
- 로컬 시연은 APK/차량 SDK 연동과 별개이며 화면에 합성 출처를 지속 표시한다. 위치·개인 이력 수집은 하지 않는다.
- 시연 검수 후 실제 선택 흐름의 사용성 피드백을 받되, 피드백 1건을 일반 수요·시장 규모로 확대하지 않는다.
