# PICKGO 사용 흐름

후속 공동 검토: [세부 설계·현대 내비/Gleo 가능성](PICKGO_DETAILED_DESIGN_2026-11-04.md). 아래 사용자 원래 흐름은 보존하며, 후속 문서의 제안과 실행 확인 수준을 구분한다.

기준일: 2026-11-04 KST. 승인 근거: 사용자가 이 채팅에서 지정한 두 사용 흐름. 이는 제품 요구사항이며 SDK 제공·실연동·구현 완료의 증거가 아니다. J-01 잠정 폐기는 유지한다.

## 1. 운전자가 시작하는 픽업 — 사용자 지정

1. 현대 자체 내비게이션 기반 검색으로 픽업할 장소를 찾고 선택한다. 검색 진입 방법은 음성인식, 직접 검색, Gleo 연동이다.
2. 선택한 장소 주변의 픽업 후보지 3곳을 제시한다. 주정차 단속구역과 버스정류장 등 대중교통 전용 정차 지점은 제외한다.
3. 후보지 하나를 선택한 뒤 지도에서 실제 픽업 위치를 세밀하게 조정한다.
4. 픽업할 사람을 선택하고 초대 메시지 보내기를 누른다. 연동된 시스템으로 대상자에게 픽업 알림과 링크를 보낸다. 대상자는 링크에서 자신의 실시간 위치를 공유하고 픽업 요청 위치를 제안할 수 있다.
5. 픽업 장소까지 경로 안내를 시작하고 대상자의 실시간 위치를 표시한다.

## 2. 탑승자가 시작하는 픽업 — 사용자 지정

1. 앱을 가진 탑승자는 사전에 연결된 차량에 픽업 요청을 보낼 수 있다.
2. 운전자 흐름과 같은 장소 검색 → 주변 후보 3곳 → 선택 → 지도 세부 조정 과정을 사용한다.
3. 차량 소지자에게 픽업 요청 보내기를 누르면 차량에 팝업과 알림을 전달한다.

탑승자 시작에는 앱과 사전 차량 연결이 필요하다. 운전자 초대 링크 참여에 앱 설치를 새로 필수화한 것으로 해석하지 않는다.

## 3. 기존 결정과 연결

- 장소 검색 결과는 주변 후보를 찾는 기준이며, 최종 승차 좌표와 구별한다.
- 2026-11-04 후보 기준 확장을 유지한다. 공식 지정 승하차 구역만 요구하지 않고 일반 승용차의 짧은 승하차를 기준으로 조사한다. 전용·금지·단속 구역은 제외하며 제한 미확인을 허용으로 취급하지 않는다.
- 기존 양측 장소 합의를 유지한다. 대상자의 제안은 확정 위치와 구분하며 수락 전에는 확정 위치를 덮어쓰지 않는다.
- 위치 공유는 동의·철회·유효기간을 갖는다. 기존 일회 공유 동의를 실시간 공유 동의로 자동 확대하지 않는다.
- 직접 검색, 지도 세부 조정, 차량 알림은 DEVELOPMENT_GUIDE.md의 플랫폼 주행 UX 제한을 따른다. 주행 중 제한을 팝업이나 사용자 확인으로 우회하지 않는다.

## 4. 다음 설계에서 확정할 사항 — 제안/미결정

- 적격 후보가 3곳보다 적으면 검증된 수만 제시하고 부족을 설명하는 방안. 수를 맞추기 위해 제외 대상이나 미확인 후보를 넣지 않는다.
- 지도에서 좌표를 이동할 때 제외 조건·차량 접근·보행 연결을 재검사하는 방안. 검증 전 위치를 추천 적합 지점으로 표시하지 않는다.
- 차량에 온 요청을 운전자가 수락·거절하는 단계와 수락 후 경로 안내 시작 시점. 사용자는 이번에 요청 알림까지 지정했으며 자동 수락은 지정하지 않았다.
- 초대 후 대상자 참여 전 경로 안내 가능 여부, 이후 위치 변경 수락에 따른 경로 갱신 시점.
- 대상자 선택의 출처(연락처/사전 연결 사용자 등), 초대 메시지 전송 시스템, 차량과 사용자 연결·해제·인증 방식.
- 탑승자용 앱 형태와 현대 내비 검색 기능을 해당 환경에서 제공하는 방법.

## 5. 구현 현황과 확인할 연동

기존 로컬 웹에는 초대 링크 참여, 준비 상태, 장소 제안·수락, 수동 도착·탑승, 위치 공유 및 합성 추천 기반이 있다. 이번 요구사항 전체가 구현된 것은 아니다.

현대 내비 장소 검색·지도 세부 조정·경로 시작의 정확한 API, 음성 검색, Gleo의 장소 검색 호출 계약, 연락 대상 선택·메시지 전송, 탑승자 앱과 차량 사전 연결, 차량 팝업·실시간 위치 전달은 각각 확인해야 한다. 기존 Gleo 준비는 조회·수동 도착 두 명령 범위로, 새 장소 검색 연동의 실행 증거가 아니다. 기존 외부 경로 공급자 제안은 현대 내비 기반이라는 이번 요구사항을 대체하는 확정 결정으로 사용하지 않는다.

이번 문서는 사용자 흐름을 기록한 것이며 코드·공개 배포·메시지 실제 발송·계정/권한 변경은 수행하지 않았다. 관련 구현과 독립 검수·실연동 시험은 미실행이다.
