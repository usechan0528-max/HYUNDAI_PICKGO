# J1 차량 디스플레이 디자인

## 최신 기준: 현대자동차 실제 화면 톤 반영

사용자 후속 지시로 아래 초안의 민트색·가로 전용 방침을 변경했다. 현재 기준은 이 절이며 아래는 공동 설계 과정 기록이다.

- 현대자동차 2026-04-30 [공식 Pleos Connect 발표 화면](https://www.hyundai.com/worldwide/en/newsroom/detail/0000001168)의 실제 이미지에서 주행 정보, 내비, Bluetooth 미디어 앱의 분할 구성을 시각 확인했다. 참조용 이미지와 색상표는 `work/cockpit-design/references/`에만 보관하며 제품 이미지로 재배포하지 않는다.
- [최신 공식 Display Layout](https://document.pleos.ai/docs/connect/guide/docs-design/getting-started/layout): 앱은 가로/세로 창 모두 대응. 시스템 Driving view·Status bar·GNB는 J1이 모사하거나 대체하지 않는다. 구형 검색 결과의 Connect-L 분류보다 현재 본문을 우선했다.
- [공식 색상표](https://document.pleos.ai/docs/connect/guide/docs-design/foundations/colors)의 Background/Button 이미지를 열어 확인. 검정·중립 차콜·회색·흰색으로 수정하고 민트 강조 제거. CSS 값은 참조 이미지에 맞춘 근사값이며 공식 원시 토큰을 추출했다고 주장하지 않는다.
- [공식 Typography](https://document.pleos.ai/docs/connect/guide/docs-design/foundations/typography)가 지정한 Asta Sans 적용. Google Fonts 원본 `google/fonts/ofl/astasans`에서 폰트와 OFL 1.1을 받아 로컬 배포. 저작권: The Asta Sans Project Authors (42dot), 2024. 라이선스는 `output/j1-cockpit/fonts/OFL.txt`에 포함.
- 공식 화면을 기준으로 앱 영역만 구성. 가로 1280×720/1024×600/1920×720, 차량 내 분할 창 640×960/480×720 검증 대상으로 변경. 세로 창은 폰 사이트가 아닌 차량의 앱 분할 영역이다. 최소 480×720은 시안의 검증 범위이지 공식 최소 사양이 아니다.
- 핵심 터치 버튼은 가로 96px, 좁은 창 88px 높이. 제목·추천 한 편·고정 제어만 유지한다. 실제 인식·오디오·플랫폼 제한 연결은 여전히 미실행이다.

추가 Claude 검수 입력/결과는 `work/cockpit-design/hyundai-input.txt`, `hyundai.json`. 공식 화면 관찰은 Codex가 수행했고 Claude가 이미지 자체를 봤다고 주장하지 않는다.

추가 검수: Haiku 5.5 세션 `4b361977-e759-4aa2-afe4-464fc8cb7250`, exit0/is_error=false. P1 음성 지원 오인→`예시` 표시와 상시 미인식 고지. P1 다음 항목 누락→자동재생은 이 시안 범위 밖임을 명시(실제 재생 로직 없음). P1 세로 높이 추정→480×720 실제 scrollHeight=720과 스크린샷으로 넘침 없음 확인. P2 음성 구분자 붙음→예시 명령 한 개로 축소. 재생 제목 중립화·마이크 상태 오인 문구·SVG 아이콘 통일·비활성 글자와 취소 버튼 명도 보완. 폰트/OFL 실제 파일 확인. 음성 일시정지 가정과 실차 미검증 유지. 마지막 문구·아이콘 수정은 Codex 재검증이며 추가 Claude 호출은 하지 않았다.

2026-11-02 · 사용자 요청: 차량 전용, 터치·음성 조작, 시작 화면에서 기능 이해, 최소 제어. 기존 웹 시연의 모바일 대응을 확대하는 대신 차량 가로 화면을 별도 설계했다. 현재 산출물은 로컬 상호작용 시안이며 Android 앱 통합 완료가 아니다.

## 화면과 동작

- 첫 화면: 앱의 목적, 추천 한 편, 큰 `바로 듣기`, `듣기 종료`, `말하기`. 탐색 메뉴·목록·스크롤·시크바·시연 설정 제거.
- 재생: 같은 자리의 주 버튼만 `잠깐 멈춤`으로 변경. 일시정지는 `이어서 듣기`, 종료는 새 듣기 세션을 시작하는 `바로 듣기`로 구분. 종료 후 자동 재개하지 않는다.
- 음성: 명시 버튼으로 진입, 같은 자리에서 취소. 듣는 중→처리 중→실패를 짧게 표시하고 터치 대안을 유지. 이 시안은 마이크를 사용하지 않으며 성공을 가장하지 않는다.
- 음성 입력 중 재생 일시정지·취소 후 명시 재개는 이번 디자인 가정이다. 실제 오디오 포커스·내비 안내·통화·STT 연동 정책은 별도 검증한다.
- 실제 명령 계약 제안: `들려줘`→시작/재개, `잠깐 멈춰`→일시정지, `듣기 끝내`→세션 종료. 인식 불확실·지원하지 않는 명령은 실행하지 않는다. 상세 설정 명령은 플랫폼 제한을 우회하지 않는다. 음성 성공 동작은 이 시안에 구현하지 않았다.
- 경로 입력 없음은 `경로 정보 없음 · 기본 추천`. 취향이 있는 경우에만 `취향으로 추천`, 유효 경로 근거가 있는 경우에만 운행 맥락을 표시한다. ETA를 꾸며 표시하지 않는다.
- 실제 제품의 초기화/추천 없음/미디어 오류: 재생 불가 사유 한 줄과 명시 재시도, 무한 로딩·자동 반복 없음. 이 상태들은 이번 시각 시안의 구현 범위 밖이다.
- 설정은 플랫폼이 허용하는 정차 상태에서만 제공할 후속 화면이며, 현재 화면에는 실제 설정 진입이나 제한 해제 버튼이 없다.

## 시각 기준과 근거

가로 1280×720 기준, 1024×600·1920×720 보조 검증. 어두운 중립색 바탕, 밝은 녹색 주 동작, 큰 한글 제목, 고정된 버튼 위치, 애니메이션 없음. 폰 전용 축소 레이아웃은 만들지 않는다. 폰 크기에는 시안의 최소 표시 크기를 안내한다.

버튼 높이 96 CSS px·간격 24px 이상을 시안 기준으로 사용한다. Google 차량 디자인의 [터치 크기 76×76dp](https://developers.google.com/cars/design/automotive-os/design-system/sizing), [가독성·터치 간격 원칙](https://developers.google.com/cars/design/design-foundations/visual-principles)을 2026-11-02 조회했다. CSS px를 Android dp나 실제 물리 크기와 동일시하지 않는다. Pleos의 최종 UI 영역·밀도·시스템 바·운전자 도달 거리·주간 반사·실차 가독성은 미검증이다. 공식 적합 인증이 아니다.

## Claude 공동 설계·검수와 처리

최소 요구사항/범위와 고정 입력만 전달, 도구·소스 수정 없이 수행. 원본 `work/cockpit-design/plan-input.txt`, `plan.json`, `review-input.txt`, `review.json`.

- 설계: 실제 Claude Opus 5.5, 세션 `eab6a16a-ba35-4553-9221-1f09ddd08ac2`, exit 0, is_error=false.
- 소스 검수: 실제 Claude Haiku 5.5, 세션 `24199bb5-2555-425c-814e-6e40881c37c4`, exit 0, is_error=false.
- Opus P1 경로 맞춤 단정/영구 확인 중: 중립 제목·경로 없음·기본 추천으로 반영. 시연 고지, 같은 자리 취소, 실패 후 터치, 종료/일시정지 구분, 두 줄 제목 한도 반영.
- Haiku P1 제목을 원래 맞춤 문구로 되돌리기: 미반영. Opus의 근거 없는 경로 주장 지적을 우선하며 상태별 제목은 사용자가 현재 동작을 이해하도록 유지한다.
- Haiku P1 마이크를 재생 행으로 옮기기: 별도 음성 영역을 유지한다. 항상 같은 우측 위치이며 모달 없이 취소·오류를 표시한다. 세 버튼은 하나의 화면에 있고 위치 안정성을 실제 브라우저에서 검사한다. 최적 도달성은 실차 검증 대상이다.
- Haiku P1 자동 이어듣기 미확인 주장: D-015와 기존 웹 재생 검증을 최소 입력에 충분히 포함하지 못한 검수 문맥 한계다. 이 시안에는 `설계 예시`로 표시했으며 자동 재생 코드를 구현하지 않았다. 실제 차량 자동 이어듣기 성공 주장으로 사용하지 않는다.
- Haiku P1 텍스트 과다: 시연·실제 기능 구분 고지는 유지한다. 생산 화면에서는 시연 설명을 제외하고 명령 예시·한 줄 상태만 남기는 방향. 현 버전은 검토용이며 최종 양산 화면이 아니다.
- Haiku P1 취소 후 재생 상태 누락: 제목 `잠시 멈췄어요`, 주 버튼 `이어서 듣기`, 하단 명시 재개 안내가 실제로 유지되므로 별도 모달은 추가하지 않는다. 취소 안내는 음성 영역에 표시한다.
- Haiku P2 작은 화면 넘침: 1024×600에서 34px 넘침을 실제 재현하고 짧은 화면의 장식 마이크를 제거해 수정했다. 낮은 높이에서 조작 버튼은 유지한다.
- Haiku P2 색상·SVG·다음 항목·재시도: 녹색 주 동작은 Codex의 시안 선택이며 사용자 고정 색상은 없다. 다음 목록은 최소 제어를 위해 생략. 실패 후 닫기→말하기로 명시 재시도 가능. 기호는 aria-hidden과 텍스트 라벨을 병기했다. 추가 장식/화면은 보류.
- Haiku P2 주차 설정 제약: 프로젝트 DEVELOPMENT_GUIDE 5절의 기존 제한을 유지한다. 실제 플랫폼 연동 완료 주장은 하지 않는다.
