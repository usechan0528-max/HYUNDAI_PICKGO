# 독립 개발 리뷰: 픽업 약속판 (로컬 메모리 서버 + 참여자 브라우저 MVP)

**모델:** claude-haiku-5-5 (환경 정보 기준)
**방식:** 읽기 전용 리뷰입니다. 도구를 실행하거나 파일을 수정하지 않았고, plan 파일도 만들지 않았습니다. 아래의 "실행"은 제공된 테스트 출력을 가리키며, 제가 다시 실행한 결과가 아닙니다. 브라우저 동작은 모두 코드 읽기에 기반한 **추론**입니다.

## 결론

- **P0: 없음** (코드 읽기 기준)
- **P1: 1건.** 오프라인/stale 상태에서 UI가 현재 확실성을 주장합니다. 요구사항 "stale/offline UI는 현재 확실성을 주장하지 않는다"를 위반합니다.
- **서버 도메인/HTTP 계층:** 요구사항 대부분을 코드로 충족합니다. 범위 내 **조건부 승인**입니다.
- **브라우저 MVP:** P1을 고치고 브라우저 stale 테스트를 통과하기 전까지 **미승인**입니다.

## 요구사항별 확인 (추론, 코드 읽기)

| 요구사항 | 결과 | 근거 |
|---|---|---|
| pending이 합의 장소를 바꾸지 않음 | 충족 | `r.place`는 `accept` 분기에서만 바뀌고, 제안은 `r.proposal`에만 저장됩니다. |
| 방 간 토큰 교차 차단 | 충족 | 토큰은 방마다 생성되고 `auth`는 해당 방의 driver/rider와만 비교합니다. |
| 자기 제안 수락/거절 차단 | 충족 | `accept`/`reject` 공통으로 `r.proposal.by !== role`을 검사합니다. |
| stale 쓰기 차단 | 충족 | `version` 불일치 시 409입니다. 서버는 단일 스레드이고 `act`는 동기 실행되므로 동시 쓰기가 직렬화됩니다. |
| 재전송 차단 | 충족 | `requestId`는 방 단위로 기록되고, 성공한 요청에서만 추가됩니다. |
| 종료 후 쓰기 차단 | 충족 | `act`의 status 검사, `end`에서 `invite=null`, `join`의 status 검사로 막습니다. |
| 조회 lease | 충족 | 서버 발급, 자격 증명별로 분리, TTL 경계는 `< VIEW_TTL`입니다. 다른 참여자의 view는 키가 달라 쓰이지 않습니다. |
| XSS | 이상 없음 | `textContent` 사용, `href`는 origin과 ID로 구성됩니다. CSP는 `script-src 'self'`입니다. |
| 정적 파일 | 이상 없음 | 고정 화이트리스트이고 경로 탐색 경로가 없습니다. |

## 발견 사항

### P1-1. stale 상태에서 현재 확실성 주장 (UI, `app.mjs` `render()`)

- **위치:** `render()`의 `readyText`, `proposal`/`proposalText`, `lastEvent` 대입부입니다. 스냅샷에 줄 번호가 없어 함수와 식별자 기준으로 적었습니다.
- **근거:** `headline`, `placeLabel`, `connection`은 `valid`로 바뀌지만 위 세 항목은 `valid`를 보지 않습니다. `#facts.stale`은 투명도 0.5만 적용합니다.
- **영향:** 연결이 끊긴 뒤에도 "준비 완료", "상대가 이 장소를 제안했어요. 수락할까요?", 마지막 이벤트 문구가 현재 상태처럼 보입니다. 수락/거절 버튼은 비활성화되므로 잘못된 쓰기는 막히지만, 사용자가 잘못된 상태를 믿을 수 있습니다.
- **최소 수정:** `!valid`일 때 세 항목에 "마지막 확인 기준 · 현재 미확인"을 붙이거나, `#proposal`과 준비 상태 문구를 숨깁니다.
- **검증:** 브라우저에서 한쪽 탭의 준비 상태를 바꾼 뒤 다른 탭을 오프라인으로 만들고, 문구에 현재 확실성 주장이 없는지 확인합니다.

### P2-1. 종료 이벤트 문구의 주체 오류 (`domain.mjs` `act`, accept/reject 분기)

- **근거:** `lastEvent`는 공유 상태이므로 수락자와 거절자도 "상대가 수락해…", "상대가 거절해…"를 봅니다. 수락한 쪽에게는 사실과 다릅니다.
- **영향:** 한쪽 화면에 잘못된 주체가 표시됩니다. 장소 변경 결과 자체는 맞습니다.
- **최소 수정:** 주체 중립 문구를 쓰거나(예: "승차지점 변경이 수락되었습니다"), `lastEvent`를 `{type, by}`로 저장하고 역할별로 렌더링합니다.
- **검증:** 역할별 `lastEvent` 문구를 단언하는 테스트를 추가합니다.

### P2-2. 제안 철회 수단이 없음 (`domain.mjs` `propose` 가드, 생존성)

- **근거:** `propose`는 `!r.proposal`을 요구하고, 제안자가 철회할 action이 없습니다. 상대가 응답하지 않으면 제안이 `end` 전까지 남습니다.
- **영향:** 안전 위반은 아니지만 MVP 흐름이 막힐 수 있습니다.
- **최소 수정:** 제안자만 쓸 수 있는 `withdraw` action을 추가합니다.

### P3-1. 클라이언트 신선도 기준 시점 (`app.mjs` `adopt`/`fresh`)

- **근거:** `received`는 응답 수신 시점에 기록됩니다. 서버 lease는 발급 시점부터 8초입니다. 응답 지연이 길면(최대 4초 timeout) 클라이언트가 "방금 서버에서 확인"을 표시하는 동안 lease가 이미 만료될 수 있습니다.
- **영향:** 정상 로컬 지연에서는 드뭅니다. 쓰기는 서버가 409로 막습니다.
- **최소 수정:** 요청 시작 시각(`fetch` 호출 전 `performance.now()`)을 `received`로 기록합니다.

### P3-2. 기타 (영향 낮음)

- `join` 경로에 `encodeURIComponent`가 없습니다. 서버 정규식이 막으므로 실질 위험은 낮습니다.
- `history.replaceState`가 초대 해시를 지웁니다. 참여 전에 새로고침하면 초대 링크를 잃습니다.
- `act()`는 `!fresh()`일 때 아무 메시지 없이 반환합니다.
- `api()`는 JSON이 아닌 오류 본문에서 원시 `SyntaxError` 문구를 보여줄 수 있습니다.
- 서버는 `127.0.0.1` Host만 허용합니다(추론). `localhost`로 접속하면 403이 됩니다. 사용 안내에 명시가 필요합니다.
- `server.mjs`의 `process.argv[1] === fileURLToPath(...)` 비교는 Windows 경로 대소문자에서 실패할 수 있습니다(미확인).
- 413 응답 시 요청 본문을 비우지 않습니다. 클라이언트에 연결 재설정이 발생할 수 있습니다(추론).
- 방 100개와 방당 요청 1000개 상한은 로컬 데모에서 자원 소진을 허용합니다. 생성 API에는 인증이 없습니다.
- 참여 후에도 드라이버 `sessionStorage`에 초대 값이 남습니다. 서버에서는 이미 무효입니다.
- 초대 bearer 방식은 명시된 한계입니다. 토큰 비교가 `===`인 점도 로컬 데모 범위에서는 문제가 아닙니다.

## 테스트 커버리지 공백

제공된 10개 테스트는 통과로 보고되었습니다(제가 재실행하지 않음). 다음은 추가를 권합니다.

- 다른 참여자의 view lease로 `act`를 호출하는 경우(자격 증명 분리가 쓰기 경로에서도 막는지)
- 다른 방 토큰으로 `act`를 호출하는 경우(현재는 `read`만 검증)
- rider가 join 전에 `propose`하는 경우
- proposer 본인이 `reject`하는 경우
- `lastEvent` 역할별 문구(P2-1)
- 방 상한 100개, 요청 상한 1000개
- HTTP: 415 content-type, Host 불일치(`localhost`), 다른 방 토큰으로 action 호출
- 브라우저: stale 문구 검증이 없습니다(P1-1).

## 범위 판단

- **서버 도메인/HTTP:** 코드 읽기 기준으로 범위 내 승인합니다. 제공된 테스트 결과는 신뢰하되, 재실행하지 않았음을 전제로 합니다.
- **브라우저 MVP:** P1-1 수정과 브라우저 stale 테스트 통과 전까지 미승인입니다. P2-1은 짧은 수정이므로 함께 처리하기를 권합니다.
- **실제 Gleo/SDK/ETA/주행/운영 보안 주장은 이 범위에 없으며, 코드도 그런 주장을 하지 않습니다.**
