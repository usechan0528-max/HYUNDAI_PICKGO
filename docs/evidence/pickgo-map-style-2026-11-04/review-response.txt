## 결론: P0·P1 없음. P2 1건(실측 필요), P3 2건

소스와 도구를 쓰지 않고 제공된 파일 본문과 diff만으로 정적 검토했습니다. 테스트 226/226과 Chrome 시각 검사 결과는 보고된 값을 그대로 인용했고, 재확인하지 않았습니다.

### 정적으로 확인된 항목
- **기존 ID·출처·고지:** `#map`, `#confirm`, `#coordinates`, `#roomState`, `#mapNotice`, `#error`, `#dataInfo`, `/map/data/yangjae.json` 링크, OSM 저작자표시·ODbL 링크가 모두 유지됩니다. 태그 짝도 맞습니다(main / map-shell / aside / map-options / details / selection).
- **1440 가로 넘침:** 400 + 24 + 936 = 1360이 1440 − 80 거터와 일치합니다. 고정폭 요소에 넘침 원인이 보이지 않습니다.
- **768/390 가로 넘침:** 모바일 블록에서 헤더가 wrap되고, 컨트롤이 flex-wrap이며, 긴 후보명은 줄바꿈됩니다. 390에서는 `.map-context`가 숨겨집니다. 넘침 원인은 보이지 않습니다.
- **터치 영역:** 버튼·링크 최소 높이는 48~88px입니다(Leaflet 줌 48px, 뒤로가기 52px, 확인 76px).
- **대비:** 주요 텍스트 조합(#bdbdbd/#202020, #f0c580/#29251f, 흰색/#345e42)은 4.5:1 이상으로 보입니다.

### 결함

**P2 · `experiments/pickup-board/map/page.css` (`@media(max-width:899px)` 마지막 블록)**
- 현상: 모바일·태블릿에서 지점을 누르면 결과 문구(`#selectionText`)와 확인 버튼(`#confirm`)이 화면 밖에 놓일 가능성이 큽니다.
- 근거: 899px 이하에서 `.map-page aside{overflow:visible}`, `.map-page .selection{max-height:none;overflow:visible}`이며 sticky/fixed가 없습니다. DOM 순서는 candidates → details → selection입니다. 390×844에서는 지도 54dvh 뒤에 후보 3장이 놓여 selection이 아래쪽에 위치합니다. 주석의 "선택 지점과 행동을 항상 보이게"는 데스크톱(≥900)에서만 성립합니다. 이 판단은 추정이며 실측이 필요합니다.
- 최소 수정 방향: `position:sticky`는 aside 높이가 콘텐츠와 같아 효과가 없습니다. 899px 이하에서 `.map-page .selection{position:fixed;left:0;right:0;bottom:0;z-index:5;max-height:45dvh;overflow:auto}`로 바꾸고 `.map-page main`에 하단 여백을 주는 방식을 검토하세요. 390×844와 768×1024에서 Chrome으로 확인해야 확정할 수 있습니다.

**P3 · `experiments/pickup-board/map/page.html`**
- 현상: `<details>`(지도 데이터·선택 기준)가 `#selection`보다 앞에 놓여 Tab 순서와 읽기 순서가 바뀝니다.
- 근거: 원본은 selection이 details보다 앞이었습니다. details는 기본 접힘이라 영향은 작습니다. 옮길 경우 데스크톱 aside의 `overflow:hidden`에서 잘리는지 확인해야 합니다.
- 수정 불필요 가능.

**P3 · `experiments/pickup-board/index.html`**
- 현상: 새 `/map` 링크에 id나 hidden 처리가 없어 후보·수동 단계에서도 계속 보입니다.
- 근거: 링크가 `#pickupAnchor` 등 단계 블록 밖, `#chooseManually` 옆에 있습니다. `app.mjs`가 `#chooseManually`를 숨기는지에 따라 달라지며, 제공된 소스에는 `app.mjs`가 없습니다.
- 확인 필요.

### 확인 필요(검수 범위 밖 또는 제공되지 않음)
- `index.html`이 참조하는 `/location-links.css`는 제공되지 않아 존재 여부와 내용을 확인하지 못했습니다.
- 지도 헤더 문구가 "양재사옥 픽업 지도"에서 "픽업 장소 선택"으로 바뀌었습니다. 수용 기준 밖의 문구 변경이므로 의도인지 확인이 필요합니다.
- 테스트 226/226과 Chrome 시각 검사는 재확인하지 않았습니다. 실제 차량 검증은 범위 밖입니다.
