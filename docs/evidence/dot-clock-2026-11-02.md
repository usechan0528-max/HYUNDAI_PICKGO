### 구현 검수 입력

- raw≈wall 관찰과 getter/mapper 존재는 시각 계약 증거가 아니다.
- 수신 후 elapsedRealtime 차이는 수신 후 경과시간이며 수신 이전 데이터 나이를 입증하지 않는다. 재부팅 구간도 구분해야 한다.
- REST API timestamp 또는 Android 일반 clock을 Pleos 필드 의미로 전이하지 않는다.
- 현재 보고는 기존 UNVERIFIED_CLOCK 판단을 해제할 근거를 제공하지 않는다. 구현 변경·게이트 해제·전체 SDK 검증 완료를 승인하지 않는다.
