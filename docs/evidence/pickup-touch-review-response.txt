## Review: touch-first CSS for the pickup UI (read-only, static)

I reviewed the supplied `style.css`, `index.html`, and `app.mjs` by reading them. I made no edits, ran no tools, and wrote no plan file. This is a static read, not a rendered check, so the layout findings below need confirming in DevTools.

**P0: none found.** Nothing blocks use, and the domain and app logic are untouched.

### P1

1. **Later `.cockpit{min-height:0}` silently overrides the earlier min-heights.** The new block comes after the `max-width:899px` and `max-width:479px` rules, which set `min-height:720px`. Same specificity, later wins, so 720px never applies. The 600px base is also overridden. Either the shrink is intended or it isn't, but the file currently says both things.
   - *Minimal fix:* keep `.cockpit{min-height:0}` (the inner scrollers already handle short heights) and delete the `min-height:720px` declarations in the two older media blocks.

2. **Centered scroll containers clip their top content.** `.welcome`, `.edit-place`, and `.end-confirm` use `align-items:center` with `overflow-y:auto`. When content is taller than the box, it overflows equally at top and bottom, and the top part cannot be scrolled to. The `max-height:760px` rule fixes only short windows, so a window roughly 761–850px tall can still hit this.
   - *Minimal fix:* `align-items:safe center` (where supported), or `align-items:start` for those three selectors.

### P2

3. **Focus rings are clipped at the edges.** The scrollers have `overflow-x:hidden`, and the buttons sit flush against their edges (`.place-options` at full width, and `.bottom` with no horizontal padding). The 3px outline plus 4px offset extends 7px past the box and gets cut off on the left and right.
   - *Minimal fix:* `padding-inline:8px` on `#board`, `.welcome`, `.edit-place`, and `.end-confirm`, or on `.bottom` alone for the board.

4. **Selected ready state disappears while disabled.** `#readyButtons button:disabled{background:#272727;color:#a5a5a5}` has specificity (1,1,1), which beats `#readyButtons [aria-pressed=true]` (1,1,0). During busy or stale periods, the chosen "준비됐어요" or "아직 준비 중" looks identical to the unchosen one. Only `aria-pressed` carries the state, so the state is lost visually.
   - *Minimal fix:* delete the rule. The generic `button:disabled` already covers the grey, and the pressed fill is preserved. If a dimmed selected state is wanted, use `#readyButtons [aria-pressed=true]:disabled{background:#bdbdbd;color:#161616}`.

### P3

5. **Pull-to-refresh is disabled** by `overscroll-behavior-y:none` on `html,body`. This is probably intended since the "다시 확인" button exists. Confirm it's deliberate.
6. **The sticky `.bottom` bar covers scrolled content** with a solid `#121212` background and no fade. This matches "persistent bottom actions," but expect content to slide under it.
7. **`::-webkit-scrollbar` rules are redundant** in Chromium 121+, where `scrollbar-color` and `scrollbar-width` take over. Harmless.

### Checked and OK

- **Animation restart during polling:** `render()` runs every 500ms, but it assigns `hidden` the same value on each pass, so nothing toggles and the 180ms entrance does not replay. It replays only when a screen actually opens.
- **Reduced motion:** the entrance animation, transitions, and active scale are all disabled at the end of the file, and that block comes last.
- **Hover:** gated behind `(hover:hover) and (pointer:fine)` for all four hover rules.
- **Touch targets:** at most 76px at narrow widths, which is well above 44px.
- **Pinch zoom:** the viewport meta does not disable zoom, and `pinch-zoom` is allowed.
- **Live region:** `#lastEvent` only updates its text when it changes, so polling does not repeat announcements.

### Still needs real verification

Run DevTools device emulation at about 360×640, 844×390, and 1280×650/800 with touch enabled, and with "Emulate CSS prefers-reduced-motion" on. Check each scroll container's bottom edge and focus rings after tabbing to the edge buttons. This review does not establish real finger or vehicle behavior.
