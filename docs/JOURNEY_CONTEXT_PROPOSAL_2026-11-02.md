# 이번 운행을 이해하는 콘텐츠·정보 추천 — 검토안

상태: **D-014 사용자 결정으로 주력안 확정·보완 중.** 이전 독립평가 Codex76.5/Opus77.0, 종합76.75는 개선 전 기준점으로 보존한다. 이후 사용자 지시가 종전 폐기 판정을 대체한다. 구현·SDK·실차·수요 검증은 미실행. 기존 단순 오디오 편성 A9와 분리한다.

## 문제와 가치
차주는 매번 운행 목적과 들을 콘텐츠를 지정하지 않아도, 이번 이동의 맥락과 자신의 취향에 맞는 콘텐츠·정보를 받아 선택 수고를 줄인다. 핵심은 차량을 추천 결과를 재생하는 화면이 아니라 추천 판단의 입력으로 사용하는 것이다. '최적'은 현재 목표 표현이며 실제 우월성을 입증한 결과가 아니다.

## 핵심 흐름
1. 사용자가 허용한 위치·운행 패턴과 선호만 사용한다. 내비 목적지·경로가 있으면 이를 우선한다.
2. 내비가 없으면 출발 지역, 요일·시간대, 초기 이동 경로와 로컬 과거 패턴으로 목적 지역 및 이동 길이 범위를 추정한다. 경로 추정과 콘텐츠 추천의 확신 정도를 구별한다.
3. 운행 목적(통근 등), 이동 길이(단거리/장거리), 남은 시간을 별도 축으로 둔다. 장거리 통근도 가능하므로 통근과 장거리를 서로 배타적인 분류로 두지 않는다. 출근길 정체로 시간이 늘었다고 여행으로 바꾸지 않는다. 반복 경로의 의미는 사용자가 확인한 라벨로만 표시하고, 근거가 부족하면 유형 미확인이다.
4. 운행 맥락과 사용자 선호를 결합해 하나의 재생 대기열을 준비한다. 관련 정보는 출처·시점이 확인되고 내비 안내와 중복되지 않을 때만 포함한다.
5. 경로가 바뀌어도 현재 재생을 강제로 교체하지 않는다. 다음 항목부터 반영하며, 위치/기록이 없거나 오래되면 일반 취향 추천으로 돌아간다. 자동 재생은 별도 설정과 플랫폼 지원 확인 전 전제하지 않는다.

## 예시 (제품 가설)
| 운행 맥락 | 사용자 선호 | 제안 |
|---|---|---|
| 반복되는 짧은 출근 | 뉴스 | 선호 분야 짧은 브리핑 |
| 같은 출근길의 긴 정체 | 뉴스·강의 | 유형은 출근으로 유지, 길이 범위에 맞춰 다음 콘텐츠 조정 |
| 평소와 다른 긴 이동 | 강의 | 이어듣기와 목적지 관련 정보 후보 |
| 귀가 | 음악 | 취향 기반 음악 중심, 불필요한 정보 제외 |
| 기록 없는 첫 사용 | 미확정 | 기본 설정·취향만 사용, 경로를 안다고 표시하지 않음 |

장거리=여행, 출근=뉴스 등 일률 대응을 하지 않는다. 선호는 운행 유형과 별도 입력이다.

## 최소 기능 범위
- 읽기 전용 차량 위치·내비 어댑터와 데이터 시각/유효성 확인.
- 목적지 없는 반복 이동의 패턴 추정, 미확인 상태, 정차 중 사용자 정정.
- 맥락과 취향을 결합하는 큐 선택 및 부적합할 때 취향만 쓰는 대안.
- 권리 확인 콘텐츠의 자체 재생과 중단·이어듣기, 플랫폼 제한 적용.
- 추정 근거·정정·추천 변경 기록을 최소한 로컬에 보관. 원시 위치 외부 전송은 별도 범위 결정.

목적지 입력만 받아 재생하는 시연으로 경로 예측이 완성됐다고 하지 않는다. 차량 공유 시 프로필 혼동, 기록 보관·삭제, 오디오 공급과 권리는 미해결 설계 항목이다.

## 검증할 질문
- 목적지 없는 운행의 초기 시점에서 예측 가능한 범위는 어디까지인가?
- 단순 시간대 규칙 또는 취향만의 큐보다 실제 재선택 수고가 줄어드는가?
- 평일 예외 이동·정체·경로 이탈·공유 차량·위치 지연에서 잘못 확신하지 않는가?
- 콘텐츠 교체 빈도와 정정 부담이 이득을 상쇄하지 않는가?

예측 정확도만 최적화하지 않는다. 잘못 확신한 비율, 미확인으로 남긴 비율, 정정 횟수와 실제 콘텐츠 재선택 수고를 함께 본다. 임계값·표본 크기·평가 결과는 아직 확정되지 않았다. 과거 운행을 학습/평가 양쪽에 섞어 성능을 부풀리지 않는다.

## 주력 보완 v2 — D-014 적용

### 제품 약속과 우선순위
매번 들을 것을 찾지 않아도 이번 운행에 맞는 큐 하나를 준비한다. 경로 예측은 이 경험을 위한 입력이며 예측 자체를 사용자에게 반복 확인시키지 않는다. 초기 가치는 콘텐츠 선택 수고 감소로 검증한다. 광고·제휴 수익이나 유지율은 아직 입증되지 않았다.

1. **목적지 없는 여정 판단:** 출발 지역·시간대·초기 이동을 과거 여정과 비교하고 복수 후보를 유지한다. 공통 구간에서는 목적지를 단정하지 않는다. 운행 목적은 사용자 확인 라벨만 사용하며 길이·시간과 별개다.
2. **불확실성에 맞춘 추천:** 후보 여정들에 두루 적합한 콘텐츠를 우선한다. 경로 판단 근거와 취향 적합도를 분리한다. 낮은 근거 상태에서는 취향만 사용한다. 추정 점수를 검증된 확률처럼 표시하지 않는다.
3. **재생의 연속성:** 경로 변경은 다음 항목에만 반영한다. 현재 재생은 유지하고 후보가 자주 바뀌는 경우 큐 갱신을 억제한다. 사용자가 직접 고른 항목은 자동으로 덮어쓰지 않는다.

초기 정보 기능은 명시된 내비 목적지 또는 사용자가 확인한 목적지의 정보로 제한한다. 추정 목적지에 대한 자동 정보 제공은 후속 실험 대상이다. 콘텐츠의 운행 맥락 추천과 무목적지 경로 추정은 초기 핵심에 남긴다.

### 최소 세로 흐름과 검증 범위
로컬 합성 여정 이력 → 현재 위치 순차 입력 → 후보 경로/유형 추정 → 선호와 결합한 큐 및 근거 → 경로 이탈/입력 단절 시 대안. 초기 콘텐츠는 재생 권리가 확인된 제한된 카탈로그와 명시적 주제·길이 메타데이터를 사용한다. 데이터 확보 전 가상 카탈로그는 오직 논리 테스트용으로 표시한다. 타사 재생 서비스의 로그인·전사·재생 권한을 전제하지 않는다.

|---|---|---|

### 개선을 판정하는 비교
같은 콘텐츠 집합으로 A(취향), B(시간대+취향), C(차량 여정 맥락+취향)를 비교한다. 선택에 걸리는 시간·재선택/정정 수고와 잘못된 고확신 판단·미확인 비율을 함께 본다. 시간 순서로 학습과 평가를 나누며 미래 경로가 현재 입력에 섞이지 않도록 한다. 합성 여정은 상태/오류 논리만 검증하고 실차 정확도·사용자 만족·사업성을 증명하지 않는다. 수치 목표는 측정 방식과 기준선이 정해진 뒤 설정한다.

### 반론 반영 시 추가 계약
- 분기 직전 운전자 확인 팝업은 초기 범위에 넣지 않는다. 확인·정정은 플랫폼이 허용하는 정차 상태에서만 한다.
- '공통 적합'은 길이만이 아니라 취향·최근 중복·사용자가 확인한 운행별 선호를 함께 사용한다. 이어듣기가 가능하다는 이유만으로 모든 상황에 적합한 것으로 처리하지 않는다.
- 통근(목적)과 장거리(규모)는 별도 필드다. 평일 출장에 통근 의미를 자동 부여하지 않는다.
- 전체 운행 비교와 사전 정의한 예외 구간 비교를 함께 보고한다. 특정 예외만 골라 전체 효과로 확대하지 않는다.
- 통화 감지 연동은 미확인으로 초기 필수 범위에 넣지 않는다. 스킵 이유를 관측하지 못하면 unknown으로 남긴다.

### Claude 회의 결과와 처리
