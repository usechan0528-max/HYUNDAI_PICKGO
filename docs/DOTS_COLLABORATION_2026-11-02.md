# ChatGPT Dots 협업 준비

사용자가 말한 Dots는 ChatGPT 내 Dots다. 아이디어 선정 후 필요한 업무·반복작업을 나누고 결과를 교환하도록 조건부 승인했다. 아이디어80/90탐색 목표는 유지한다.

## 확인 사실

- [공식 업데이트](https://learn.chatgpt.com/docs/whats-new/dots-october-9-2026): Dots가 기존 Codex 작업을 이어가고 결과를 확인할 수 있다고 설명한다.
- [작업과 기억](https://learn.chatgpt.com/docs/dots/tasks-and-memory): 연결된 컴퓨터의 기존 로컬 Codex 작업을 이어갈 수 있다. 작업 문맥은 선택적으로 전달되며 모든 대화가 자동 공유되는 것은 아니다. 고정시간 반복은 저장된 일정이 필요하다.
- 현재 세션 ALL_TOOLS에 Dots 직접메시지 도구를 발견하지 못했다. cua inventory에는 Dot 브라우저 표면이 없었다. ChatGPT.app 접근은 컴퓨터제어 도구가 safety reasons로 거절했다. 동일대상 우회·권한변경 없음.
- 따라서 Dots→Codex는 문서상 지원, 현재Codex→Dots 직접전달/회신회수는 미검증이다. 양방향 연결이나 자동 실행을 완료했다고 주장하지 않는다. 이는 Dots 전체가 제어불가하다는 뜻이 아니다.

## 선정 후 전달 묶음

대상: HYUNDAI_AI 프로젝트의 선정된 아이디어에 한정.

1. 작업ID와 목표, 제품후보버전, 필요한자료 링크/최소발췌.
2. 한정된 업무: 공식자료 변경 확인, 출처별 사실 대조, 테스트케이스 후보 정리 등.
3. 산출물: 요약·출처/확인시각·미확인·반론·다음조치. 외부게시/연락/수정은 별도 범위 없으면 수행하지 않음.
4. 코드변경은 기본제외. 위임할때 파일소유/제외범위를 별도지정. Codex최종통합, Claude개발검수 유지.
5. 같은작업 결과를 받고 필요한후속질문을 보낸다. 전달성공/회신수신/검증완료를 별도로 기록한다.
6. 실제 예약반복은 업무·주기·종료조건·결과위치를 정한뒤 저장과확인. 의미있는변경/실패/사용자판단필요시에만 알림.

## 사용자가 Dots에서 시작할 때 쓸 짧은 문구

“HYUNDAI_AI의 기존 Codex 대화를 찾아 현재 아이디어 선정 상태를 확인해. 새 대화를 만들지 말고 기존 작업을 이어가. 아이디어 선정 전에는 별도 개발을 시작하지 마. 선정 후 Codex가 정한 범위의 조사·반복작업만 맡고 결과·출처·실패를 기존 작업에 전달해. 공개·외부연락·계정·권한변경은 하지 마. 먼저 접근 가능한 작업과 회신 경로를 확인해 알려줘.”

이 문구는 준비안이며 실제로 Dots에 전송하지 않았다. 사용자가 직접전달해야하는 상황이 생기면 자동전송한것처럼 말하지 않는다.
