# 양재 실제 지도 픽업 선택 · 2026-11-04

사용자 승인: 실제 지도 연동, 확인 가능한 정차 금지·물리적으로 부적절한 지점 차단, 나머지 자유 핀, 양재사옥 기준 실제 후보 표시. 로컬 구현이며 공개/push 없음. J-1 개발 제외.

## 실행과 구현

`node experiments/pickup-board/server.mjs` 실행 후 `/map`. 이번 시연은 http://127.0.0.1:4193/map 에서 실행했다. 기존 synthetic-diagram 좌표와 실제 WGS84를 혼합하지 않는다.

- map/geometry.mjs, model.mjs: 실제 OSM 객체 기반 건물·수역·고속도로·정류장·횡단보도·정차금지 태그 및 교차로 추정 보호범위 판정. 주차만 금지는 정차금지로 취급하지 않음.
- map/board.mjs, domain.mjs, server.mjs: 생성/제안/수락 서버 재검증. GET /api/map, POST /api/map/check {point:[경도,위도]}, POST /api/rooms {point}, proposePoint 액션. 기존 역할·버전·동의 초기화 유지.
- 인증된 GET /api/rooms/:id의 mapPoint는 확정 좌표, proposal.mapPoint는 미확정. 내비는 확정 좌표만 사용해야 한다.
- map/page.* 및 index.html: 실제 지도, 3개 후보, 자유 선택, 차단 이유, 데이터 한계·상대 공유 고지. 배경은 OSM 타일, Leaflet1.9.4 로컬 배포. GPS 수집 없음. 조회 영역/IP는 타일 서버에 전달된다.

## 실제 후보

아래는 실측 정차면이 아니라 OSM의 명시된 도로폭에서 계산한 일반도로 가장자리 추정점이다. 공식 픽업구역만 요구하지 않는다. 폭 미상 도로는 자동추천에서 제외하지만 수동 선택은 허용한다.

## 데이터 출처와 한계

실제 OSM API v0.6 bbox export `[127.032,37.455,127.050,37.471]`와 relation/6942680/full.json을 1회 수집해 map/data/yangjae.json 1327개 객체로 정규화했다. 런타임에서 편집 API를 반복 호출하지 않는다. 공개 배포 데이터에 mapper 계정 메타데이터를 포함하지 않았다.

[OSM 저작권·ODbL](https://www.openstreetmap.org/copyright), [타일 정책](https://operations.osmfoundation.org/policies/tiles/), [API v0.6](https://wiki.openstreetmap.org/wiki/Api06). Leaflet LICENSE 동봉.

범위는 양재 일부이며 정부의 완전한 정차금지 GIS가 아니다. 미수록 금지표지·어린이보호구역·시간제/임시통제는 누락될 수 있다. 교차로 버퍼와 일부 도로폭은 추정이며 오차·과차단 가능성이 있다. 따라서 모든 불법 지점 차단 또는 추천점의 합법성을 보증하지 않는다. 이 한계는 UI에도 표시한다. 실제 현장 표지·교통상황 확인은 미실행이다.

판정 데이터 7일 만료 후 신규핀/수락 차단, 추천 숨김. 자동 갱신 작업은 없음. import_osm.py는 로컬 OSM JSON 정규화 도구이며 입력 파일 mtime을 수집시각으로 사용하므로 원본 다운로드 시각을 보존해야 한다. 잘못된 도로 그래프/불완전 다중폴리곤은 조용히 누락하지 않고 로드 실패한다.

## 검증

`node --test experiments/pickup-board/*.test.mjs`: 최종219/219 통과, 종료0. 동시 작업자의 routo 테스트도 포함된 당시 전체 집합이며 지도 전용13개 시험. tests 로그 참조. 새로운 회귀는 정차금지 우회·만료시 수락·명시폭 없는 추천 제외·단위 혼합 폭 제외·폴리곤 안뜰을 검증한다.

Chrome 실제 UI: OSM 타일 로드, 추천 선택 활성화, 사옥 건물 클릭 차단, 참여자 초대·제안·상대 수락 후 좌표변경 확인. 최종 후보 변경 후 선택/건물 차단을 다시 확인했다. 데스크톱1440x900 확인; 모바일 실기·실차 미실행. 별도 Android 내비 통합은 별도 채팅 책임이며 이 결과를 해당 검증으로 확대하지 않는다.

Claude Haiku5.5 실제 CLI 읽기검수2회, exit0/is_errorfalse. 원문 evidence/pickup-map-review*.json.
- P1 폭 미상 추천: 명시폭 필수로 수정. 후속 P1 parseFloat 단위 혼합: 엄격한 미터 숫자 패턴으로 수정, 회귀 통과.
- 다중폴리곤 누락/안뜰: 완전 relation 수집, importer containment 별 안뜰 배정. 거리함수는 metre projection임을 소스로 확인.
- 초록 안전표현: '지도 기준 차단 없음' 및 파란핀, 법적 보증 제거.
- 만료 UI/타일 복구/외부 타일 전달 안내 반영.
- 후속 선 버퍼 표시 지적: page.mjs가 실제 반경을 줌별 픽셀 두께로 변환하므로 중심선만 표시한다는 가정은 해당하지 않음.
- 캐시 synthetic clock 지적: 불변 데이터 후보 계산만 기준시각 사용, 모든 응답/선택에서 실제시각 만료 게이트 적용. 보안 우회 아님.
- 인접도로 roadId는 최근접 정보이며 sourceId가 후보 생성 도로임. 실제 경로 연결 보증 없음.
- 잘못된 데이터 시작실패는 의도한 fail-closed. 좌표는 bbox로 유효 경도·위도 범위보다 엄격히 제한.

남은 제한: 법적 GIS의 완전성·실측 도로 가장자리·현장 검증, 운영용 데이터 갱신, 공개 서비스 abuse 방지. 로컬 시연 범위 완료이며 전국/운영용 완전차단은 미완료.
