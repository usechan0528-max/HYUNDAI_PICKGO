B 가칭 차량 기능 길잡이: 대상은 차량 기능을 잘 모르는 운전자. 출발 전 또는 주차 후 '불편 1개' 선택→차종·연식·사양에 맞는 근거 확인→최대 3단계 안내→도움됨/해결 안됨 피드백. 첫 불편 종류는 공식 설명서에서 정확한 조작 경로·적용 사양 확보 후 1개만 채택한다. 후보 예시는 뒤쪽 탑승자가 쉬고 싶어 하는 상황이나, 해당 기능 존재를 아직 확정하지 않는다.
지원 표시는 사용자 선택 정보에 맞는 문서상 지원/명시적 미지원/확인 불가. 문서 미기재를 미지원으로 판정하지 않는다. 실제 차량 capability와 구분. 출처 URL·사양·확인일 표시. 임의 생성형 AI 답변 없음. 직접 제어·음성·계정·서버 제외.
핵심 화면 3개: 사양 및 불편 선택 / 지원 근거+3단계 안내 / 결과 피드백. 정적 콘텐츠 구조와 모의 UX 상태를 쓴 로컬 검증용 시연부터 개발하되 전 화면에 시연 표시. 시연에서 조작한 UX 상태는 실제 주차 판정 아님. 실제 앱은 CarUxRestrictions 등 검증된 플랫폼 제약을 따르고 unknown/단절/주행 제한이면 상세 안내와 입력 차단. 속도 0이나 사용자 주차 버튼으로 해제 금지.
수용 기준: 근거 없는 사양 조합은 확인 불가; 문서 미기재를 미지원으로 오표시 0; 안내 최대 3단계; unknown/주행/단절 즉시 차단; 이전 선택을 바꾸면 오래된 지원 판정 제거; 로컬 기록 지우기 가능. 시장 검증은 별도: 5명 정지 환경에서 설명서와 비교(순서 교차), 4명 이상 정확한 경로 도달, 잘못된 지원 안내 0, 전체 소요시간/성공률 기록. 이 숫자는 제안 기준이지 통계적 입증 아님. 동률/불리면 차별화 주장 중단, 새로운 기능 무한 추가 금지. Gleo 직접 비교 미실행.
