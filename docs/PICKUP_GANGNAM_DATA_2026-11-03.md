# 강남역 첫 실지점 데이터 조사

사용자 지정: “실제 장소가 가능하다면 강남역으로 해보자.” 확인일 2026-11-03 KST. **현재 적격 실제 추천 후보0개**이며 지점이 물리적으로 없다는 뜻이 아니라, 아래 계약을 충족하는 운영 근거를 확보하지 못했다는 뜻이다.

| 조사 대상 | 확인 근거 | 아직 부족한 근거 | 현재 처리 |
|---|---|---|---|
| 강남역 출구 주변/강남대로 | 역 주변이라는 사실만으로 일반 승용차 정차 허용 아님 | 금지구역·시간·차종, 지정 승하차 구역, 입구/차로/보행 경로 | 등록하지 않음 |
| 역삼문화공원 제1호 공영주차장 | 공단2023소식지의 운영 개시·소재지 및 구청2026 보도자료의 현존 운영 언급 | 승하차 지점/주차면 좌표, 보행자 접근, 진입방향, 최신 요금/공사/이용조건, 공간 확보 | 실제 시설 조사 후보, 추천 부적격 |
| 언구비 공영주차장 | 서초구2019소식지의 시설 언급 | 최신 운영/승하차 허용·입구/보행/경로 전부 | 오래된 존재 근거만, 추천 부적격 |

주차장 안 주차면을 이용하는 유료 대안은 시설 관리자 조건·빈 주차면·보행 접근을 확인한 뒤 별도로 검토할 수 있다. 주차장 입구/진출입로 앞을 승하차 허용 구역으로 바꾸지 않는다. 오래된 소식지 요금을 현행 비용으로 표기하지 않는다. 비공식 지도/블로그의 건물중심 좌표를 검증된 픽업 좌표로 복사하지 않는다.

## 경로 공급자 제안과 비용 경계

TMAP은 자동차·보행자 경로를 한 공급자에서 제공하므로 우선 기술 후보로 제안한다. [공식 서비스 소개](https://www.tmapmobility.com/service/corporate/api), [개발자 가이드](https://tmapapi.tmapmobility.com/main.html), [공식 공개 약관/제약](https://tmapapi.tmapmobility.com/terms.html)을 직접 확인했다. 해당 약관 페이지는 경로안내 일 무료1000건, 저장후24시간 이상 사용 불가를 표시한다. 실제 계정 상품의 최신 무료조건·차량 적용·과금단가는 아직 확인하지 않았다. 계정 가입/약관수락/상품신청/결제/키발급은 수행하지 않았다. 무료량을 무제한 실시간 요청 허용으로 확대하지 않는다.

1회 추천에 기준 차량경로1+후보별 차량경로3+보행경로3을 쓴다는 가정이면 최대7건이고, 일1000건을 단순 나누면142회 수준이다. 이는 설계 계산 예시이며 실제 SKU별 집계·요금이나 측정 결과가 아니다. 매 GPS callback마다 외부 API를 호출하는 방식은 채택하지 않는다. 캐시 재사용도 freshness·공급자 약관·같은 위치/경로 계약을 만족해야 한다.

카카오·네이버 검토는 기존 PICKUP_MAP_RESEARCH 보고서 참조. 장소 검색/주소변환만으로 보행경로·정차허용을 충족할 수 없다. 실제 endpoint adapter는 자격·상품·정확한 반환계약과 대장을 확정한 뒤 구현할 범위이며 현재 내부 provider 인터페이스를 실제 TMAP 호출 코드라고 부르지 않는다.

## 다음에 필요한 구체 입력

1. 강남역 주변 일반 승용차 승하차 허용 구역 또는 허용된 주차면/시설관리자 조건과 유효시간, 검증된 차량/보행 입구 좌표·접근 방향. 외부 관리자에게 문의 메시지는 보내지 않았다.
2. TMAP 계정의 자동차·보행자 API 사용 가능 여부와 비용 한도, 차량 내 이용·데이터 보관 조건 확인. 키는 채팅·저장소에 붙여넣지 않는다.
3. 실제 차량 위치/경로 신선도 계약과 native 인증 전달, 탑승자 HTTPS 수집 및 외부 경로 전송 동의. 이 조건이 준비되기 전 실데이터 추천은 서버에서 차단한다.
