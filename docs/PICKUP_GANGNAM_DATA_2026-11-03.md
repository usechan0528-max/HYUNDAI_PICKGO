# 강남역 첫 실지점 데이터 조사

## 2026-11-04 최종 사용자 기준 및 구현

최신 지시가 앞선 대장 중심·미확인 제외 기준보다 우선한다. 잠깐의 정차도 금지된 지점, 일반차 이용 불가 전용 공간, 폐쇄·차량 접근 불가 및 건물 내부/고속도로 차로 등 비정상 위치는 추천과 선택에서 차단한다. 공식 승하차 지정과 `pickupAllowed=true`, 60초 이상 허용은 필수 조건이 아니다. 그 외 미확인 조건은 안내하면서 사용자 책임으로 선택할 수 있다. 주차만 금지된 곳과 정차 자체가 금지된 곳을 구분하며 CCTV 존재만으로 정차 금지라고 판정하지 않는다. 현장 표지·교통 상황 확인과 실제 정차 판단 책임은 사용자에게 있다.

`eligibility.mjs` 공통 판정, engine의 선택 가능한 후보 평가, board의 선택/수락 재평가 및 수동 생성·제안·수락 제한 검사, 화면의 미확인 안내를 구현했다. 금지 사실이 누락·오래된 응답으로 사라지지 않도록 보존하고 새로운 명시적 해제 정보로만 갱신한다. 합성 공급자는 공식 지정이 없는 일반 도로변을 시연한다. 실제 지도/금지영역 폴리곤/도로 스냅과 임의 지도 핀 UI는 아직 미연동이다. 현재 선택 범위는 기존 이름 기반 장소 목록이며 전국 임의 좌표의 불법 여부를 판별하는 기능이 완료된 것은 아니다.

현재 사례 기준점은 현대자동차 양재사옥. [양재 후보·구현·검증 기록](PICKUP_YANGJAE_2026-11-04.md)을 따른다. 아래 11월 3일 문구와 11월 4일 초기 설계는 과거 기록이다.

## 2026-11-04 사용자 변경 — 일반 승용차의 짧은 승하차 기준

공식 지정 승하차 구역만 찾는 기존 조사 범위를 폐기한다. 일반 승용차가 택시처럼 탑승자를 만나 짧게 승하차하는 상황을 기준으로 일반 도로변과 접근 가능한 시설 앞 공간도 후보로 조사한다. ‘택시처럼’은 이용 흐름을 뜻하며 택시·버스 전용 공간의 이용 자격을 부여하지 않는다.

- 버스 등 대중교통 전용 정차 공간, 일반 승용차가 이용할 수 없는 택시 전용 공간, 주정차 금지·단속 구역, 폐쇄·진입 제한 지점은 제외한다.
- 공식 픽업 구역 지정이나 시설의 승하차 허용 대장 등재 여부는 필수 조건이 아니다. 도로·표지·시간대별 제한·단속 정보·차량 접근·보행 연결 근거를 함께 확인한다.
- 금지 정보가 검색되지 않았다는 이유만으로 정차 가능을 확정하지 않는다. 제한 여부가 미확인이면 확인할 조사 후보로 남기고, 확인된 추천 후보와 구분한다.
- 장시간 대기·주차 장소를 찾는 기능이 아니다. 양측 도착 시점과 짧은 승하차 가능성, 교통·출입 방해 가능성을 고려한다. 운영상 승하차 예상시간은 법적 허용시간으로 표시하지 않는다.
- 후보 비교는 차량 동선·진입 방향·우회·탑승자 보행 부담을 함께 평가하며 자동 확정 없이 양측 장소 합의를 유지한다.

아래 2026-11-03의 ‘적격 후보0개’는 당시 엄격한 대장 계약으로 조사한 결과다. 일반 도로변 후보가 없다는 결론으로 재사용하지 않는다. 다음 조사는 강남역 주변 일반 도로변·시설 앞 공간을 포함해 다시 수행한다. 이 변경 자체가 특정 실제 장소의 정차 적합성 확인이나 실제 추천 연동 완료를 뜻하지 않는다.

사용자 지정: “실제 장소가 가능하다면 강남역으로 해보자.” 확인일 2026-11-03 KST. **현재 적격 실제 추천 후보0개**이며 지점이 물리적으로 없다는 뜻이 아니라, 아래 계약을 충족하는 운영 근거를 확보하지 못했다는 뜻이다.

## 경로 공급자 제안과 비용 경계

TMAP은 자동차·보행자 경로를 한 공급자에서 제공하므로 우선 기술 후보로 제안한다. [공식 서비스 소개](https://www.tmapmobility.com/service/corporate/api), [개발자 가이드](https://tmapapi.tmapmobility.com/main.html), [공식 공개 약관/제약](https://tmapapi.tmapmobility.com/terms.html)을 직접 확인했다. 해당 약관 페이지는 경로안내 일 무료1000건, 저장후24시간 이상 사용 불가를 표시한다. 실제 계정 상품의 최신 무료조건·차량 적용·과금단가는 아직 확인하지 않았다. 계정 가입/약관수락/상품신청/결제/키발급은 수행하지 않았다. 무료량을 무제한 실시간 요청 허용으로 확대하지 않는다.

1회 추천에 기준 차량경로1+후보별 차량경로3+보행경로3을 쓴다는 가정이면 최대7건이고, 일1000건을 단순 나누면142회 수준이다. 이는 설계 계산 예시이며 실제 SKU별 집계·요금이나 측정 결과가 아니다. 매 GPS callback마다 외부 API를 호출하는 방식은 채택하지 않는다. 캐시 재사용도 freshness·공급자 약관·같은 위치/경로 계약을 만족해야 한다.

카카오·네이버 검토는 기존 PICKUP_MAP_RESEARCH 보고서 참조. 장소 검색/주소변환만으로 보행경로·정차허용을 충족할 수 없다. 실제 endpoint adapter는 자격·상품·정확한 반환계약과 대장을 확정한 뒤 구현할 범위이며 현재 내부 provider 인터페이스를 실제 TMAP 호출 코드라고 부르지 않는다.

## 다음에 필요한 구체 입력

1. 강남역 주변 일반 도로변·시설 앞 공간을 포함한 짧은 승하차 후보의 좌표·진입 방향·보행 접근, 전용/금지/단속/시간대 제한과 확인 근거. 공식 지정 구역이나 허용 대장 등재는 필수 조건이 아니다. 외부 관리자에게 문의 메시지는 보내지 않았다.
2. TMAP 계정의 자동차·보행자 API 사용 가능 여부와 비용 한도, 차량 내 이용·데이터 보관 조건 확인. 키는 채팅·저장소에 붙여넣지 않는다.
3. 실제 차량 위치/경로 신선도 계약과 native 인증 전달, 탑승자 HTTPS 수집 및 외부 경로 전송 동의. 이 조건이 준비되기 전 실데이터 추천은 서버에서 차단한다.
