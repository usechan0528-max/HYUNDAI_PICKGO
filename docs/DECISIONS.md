## D-001 · 2026-11-02 · 공동 이용 조율 가설 검증

- 사용자 요청: 추천대로 진행한 뒤 심층 평가 요청.
- 승인된 방향: 차량 기능·서비스 접근을 쉽게 만드는 목표 아래 공동 이용 조율을 우선 검토한다.
- 범위: 조사, 평가, 검증 계획. 전체 제품 구현·물리 제어·공개·제출은 확정하지 않는다.
- 실차: 사용자의 최종 정정은 접근 불가. 앞선 접근 가능 답변은 사용하지 않는다.
- 평가: [심층 평가](COORDINATION_EVALUATION_2026-11-02.md). 평균 65점으로 자체 통과 기준 미달. 본 개발 확대 전 수요·API 확인을 권고한다.
- 상태: 방향 검증 진행을 승인받음. 제품 채택·폐기는 미결정.
- 재검토 조건: 반복 수요, 핵심 API 권한, 실제 Gleo 대비 효과 확보.
- 언어/UI/서버/AI 공급자/저장 정책/제출 수준: 미결정.

기존 지침 파일의 ‘주제 미확정’ 문구는 작성 당시 상태다. 이 기록은 최신 사용자 요청을 좁게 반영하며, 기존 정책을 변경하지 않는다.

## D-002 · 2026-11-02 · 역할별 회의와 추천안

- 승인: 사용자가 준비된 회의 전달문의 Claude 전송과 후속 의견 교환을 명시 승인. 같은 범위의 반복 확인 없이 진행하도록 요청.
- 실행: 동일 Claude 세션에서 후보 검토와 Codex 수정안 검토 2회 완료.
- 추천: [차량 기능 길잡이의 최소 범위](RECOMMENDED_MVP_2026-11-02.md). 조건부 검증 개발안이며 시장성·SDK 성공 판정이 아니다.
- 경유 조율·가족 메모는 보류. 구체 첫 기능은 실제 어려움 사례와 공식 근거 확보 후 선정.
- 이번 산출물: 추천안과 수용 조건 정리. 앱 구현·사용자 시험은 미실행.

## D-003 · 2026-11-02 · Claude 역할별 모델 지정

- 승인자: 사용자. 아이디어 회의 응답은 **Opus 5.5**, 개발 과정의 검수 응답은 **Haiku 5.5**로 지정했다.
- 적용: 이후 Claude 호출에서 역할에 맞는 정확한 모델 ID를 확인하고 `--model`로 명시한다. 같은 세션의 후속 호출에도 명시한다. 최신 모델을 가리키는 일반 별칭만으로 지정 버전을 충족했다고 간주하지 않는다.
- 사용 불가 또는 식별 불가: 임의 모델 대체나 자동 fallback 없이 해당 호출의 차단 사유를 보고한다.
- 검증 상태: 설치된 CLI의 `--model` 옵션 지원은 확인했다. 두 지정 버전의 정확한 ID·계정 가용성과 실제 호출은 아직 확인하지 않았다.
- 과거 회의는 명시적 모델 지정 없이 실행했다. 이번 선택을 과거 실행에 소급해 Opus 5.5 사용으로 기록하지 않는다.
- Codex의 메인 기획·구현·통합 역할과 Claude의 기본 소스 수정 없는 검수 역할은 유지한다.

## D-004 · 2026-11-02 · 새 후보 탐색

## D-012 · 2026-11-02 · 일반 차주의 일상 반복 사용으로 대상 고정
