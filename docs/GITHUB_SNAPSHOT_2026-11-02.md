# GitHub 개발 보존과 아이디어 분리 · 2026-11-02

사용자가 이전 개발의 커밋·GitHub 업로드와 새 아이디어의 동일 저장소 별도 브랜치 업로드를 승인했다. 저장소 비공개 설정은 유지한다.

- main: 기존 주차/J1 웹·Android 소스, 한국어 AI 음원/라이선스, SDK 진단 소스, 기존 검증 증거 및 debug APK 0.1.0/0.2.0.
- codex/pickup-board: 선정 기획, 경쟁 조사, 토너먼트 근거. 진행 중인 픽업 MVP 구현은 이번 고정 스냅샷에서 제외한다.
- SDK/JDK/Gradle 설치물, AVD, 서명키, 로컬 설정, 캐시, 지원서/동의서 및 임시 작업 폴더는 업로드하지 않는다.
- Android 재빌드에는 별도 SDK/도구와 사용자 승인 서명 설정이 필요하다. 저장소에 서명키가 없으며 debug APK를 제출용 release로 취급하지 않는다.

이번 검증: `node --test experiments/journey-context/*.test.mjs` 125/125 통과, `cd mvp; node --test` 22/22 통과. 최초 `node --test mvp/*.test.mjs`는 확장자가 달라 0개 실행이므로 검증에서 제외하고 올바른 명령으로 재실행했다. Android 빌드/에뮬레이터/실차는 이번 업로드 작업에서 재실행하지 않았다. 기존 실행 결과는 각 기능 보고서를 따른다.

원격의 기존 DESKTOP_SETUP 커밋을 부모로 보존한다. 공유 작업 폴더의 진행 중 변경을 덮어쓰거나 브랜치를 바꾸지 않고 별도 Git index로 스냅샷을 구성한다. 소스 기능 수정은 없다. 내비 ETA/위치 시계 계약 등 기존 미해결 한계도 그대로 보존한다.

Claude 구성 검수와 지적별 처리: [검수 처리 기록](GITHUB_UPLOAD_REVIEW_2026-11-02.md). 원격 부모·고정 tree·기획 링크·APK 내부 키 패턴을 확인했다. diff 공백 점검은 원본 로그/라이선스/EOF 경고가 남아 완전 통과가 아니다.
