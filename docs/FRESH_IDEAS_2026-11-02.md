# 새 아이디어 회의 — 도착 준비 카드

2026-11-02 KST. 기존 차량 기능 길잡이의 채택을 전제로 하지 않고 다시 구상했다. Codex가 문제 가설과 반론을 주도하고 Claude Opus 5.5가 제한된 발상·검토를 수행했다. 아래는 제품 확정이 아닌 검증 후보이며 실제 사용자 수요와 SDK 연동은 미검증이다.

## 우선 후보: 도착 준비 카드

처음 가는 대형 시설을 대상으로 출발 전에 방문 목적과 공식 진입 정보를 연결한다. 사용자가 여러 웹페이지에서 정보를 찾는 부담을 줄일 수 있다는 가설이다. 핵심은 시설 주소 검색 이후의 정보 준비다. 기존 내비가 같은 정보를 충분히 제공한다면 독립 앱의 이유가 약해진다.

예시 흐름: 정차 중 시설 선택 → 방문 목적 선택 → 공식 근거가 있는 진입 정보 카드 확인. 실제 장소의 정답을 아직 제품 데이터로 확정하지 않았다. 'A홀 방문이면 어느 게이트인지' 같은 관계는 해당 공식 근거가 확보된 경우에만 제시한다.

최소 범위는 시설 1곳, 일반 승용차 방문자, 공식 안내가 있는 방문 목적 1~2개다. 출입구 명칭·적용 조건·출처·확인일을 표시하고, 접근 방향이나 이용 조건을 판단할 자료가 없으면 자동 추천하지 않는다. 카드의 선택과 읽기를 정차 환경에서 먼저 검증한다.

실시간 빈자리·주차 요금 보장·차선 변경 지시·주행 중 입력·임의 정차 권고·전국 시설 자동 수집은 제외한다. 위치 기반 도착 알림과 내비 목적지 전달은 정확한 SDK 계약·권한·플랫폼 UX 제약을 검증한 뒤 검토할 후속 범위다. SDK 연결 전 시연을 차량 연동 성공으로 표시하지 않는다.

## 확인한 사실과 미확인 가설

- 코엑스 공식 오시는 길에는 접근 방향별 게이트 안내가 있다. 이는 진입 정보가 별도로 관리된다는 사례이며, 사용자가 실제로 헤맨다는 증거는 아니다. [공식 안내](https://www.coex.co.kr/guide/directions/)
- 현대차의 2026년 10월 업데이트 안내는 Gleo의 경로상 장소 검색과 거리순 주차장 검색을 설명한다. 단순 검색은 중복 위험이 있다. 이 문서만으로 Gleo에 세부 진입 안내가 없다고 단정할 수 없다. [공식 업데이트](https://update.hyundai.com/KR/KO/updateNoticeView/wsVm9C)
- 시설 운영자가 정보를 제공·관리하는 사업 방식을 가정할 수 있으나 협력 의향·갱신 비용·수익성은 미확인이다. 수동 검수라는 이유만으로 확장 불가능하다고 단정하지도 않는다.
- 차량 화면에서 전달하는 편의가 휴대폰보다 큰지, 반복 이용할 만큼 문제가 잦은지는 미검증이다.

## 개발 전 최소 검증

1. 공식 시설 안내와 현재 지도·내비가 제공하는 정보를 동일 시설에서 대조한다. 접근 조건까지 이미 해결한다면 해당 사례를 차별화 근거에서 제외한다. Gleo 실제 비교는 실차가 없어 미실행이다.
2. 최근 해당 시설을 방문한 사람에게 입구 혼동의 실제 사례와 기존 해결법을 확인한다. 유도 질문이나 앱 사용 의향만으로 수요를 인정하지 않는다.
3. 두 조건을 통과하면 한 시설의 카드를 로컬 시연으로 만든다. 공식 안내를 직접 찾는 방식과 올바른 정보 선택·소요시간을 정지 환경에서 비교한다. 시간 개선이나 차량 안전성을 미리 약속하지 않는다.
4. 잘못된 이용 조건, 오래된 정보, 근거 충돌이면 추천을 중단하고 원문 확인으로 돌린다. 갱신 담당과 오류 신고 처리 비용도 확인한다.

정보 공백도 실제 어려움도 없으면 이 후보를 중단한다. 유효한 정보가 있어도 차량에서의 추가 가치가 없으면 공모전 차량 앱의 주력 후보로 채택하지 않는다. 이번 회의에서는 앱 구현·시설 협약·사용자 모집·SDK 실행을 하지 않았다.

## 후속 회의 결론

Claude는 긴급 절차 카드 제외와 확장성 단정 철회를 수용했다. 도착 준비 카드는 조건부 검증 추천으로 합의했다. 남은 핵심 반론은 공식 홈페이지를 휴대폰에서 직접 읽는 것보다 나은지, 목적과 입구의 연결이 공식 근거인지 사람의 추정인지다. 이 두 문제를 해소하기 전에 앱 구현으로 확대하지 않는다.

Claude가 제안한 같은 참여자 반복 비교에는 학습 효과가 있을 수 있으므로, 실제 시험 설계 때 조건별 다른 참여자 또는 동등 난이도의 다른 과업을 배정한다. 5~8명은 탐색용 제안 규모이며 대표성·통계적 우위를 보장하지 않는다. 인터뷰·모집은 아직 하지 않았다.
