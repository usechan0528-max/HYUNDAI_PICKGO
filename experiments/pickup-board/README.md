# PICKGO 웹 시연

Node.js 22 이상에서 저장소 루트 기준으로 실행합니다.

```sh
npm start
npm test
```

- 기본 주소: `http://127.0.0.1:4180`.
- 운전자: 장소 검색·선택 → 픽업 시작 → 초대 링크 열기.
- 별도 탭의 탑승자: 참여 → 준비 완료 → 장소 합의 → 도착 후 탑승 확인.
- 다인 시연: `/multi`에서 출발·탑승자·지점 설정 후 사람별 초대.
- `127.0.0.1`은 같은 컴퓨터 전용. 외부 휴대폰 접속 구성은 별도.
- 기본 웹 시연은 외부 API 키가 필요하지 않음. OSM 배경 타일에는 인터넷 연결 필요.
- 메모리 저장: 서버 재시작 시 회차 소실, 회차 최대 24시간.
- 지도 수록 범위는 양재 주변. 수집 데이터 7일 만료 시 [갱신](map/README.md) 필요.
- 실제 차량 위치·실차·주행 UX 제한·다중 내비는 미완료.
